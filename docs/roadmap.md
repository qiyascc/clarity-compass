# Roadmap

## Phase 1 - Website browser

Site profiles, URL safety, Playwright session, full-page scroll capture,
page discovery, viewports, DOM probe, snapshot capture.

## Phase 2 - Predictive heatmap

Foveacast and MediaAttention inference, ensemble and evaluation harness,
click prediction v1, overlay SDK, snapshot replay viewer.

## Phase 3 - AI UX designer

Provider ports (Anthropic first), page purpose understanding, design and UX
review, annotated findings in EN / TR / AZ / RU.

## Phase 4 - Functional auditor

Action guard, interaction tests for menus, buttons, forms, search, filters,
navigation; verified functional findings with evidence.

## Phase 5 - Advanced analysis

Accessibility audit, conversion analysis, prioritisation, reports,
before / after simulation, browser extension.
